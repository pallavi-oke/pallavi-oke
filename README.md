## What this profile is

This GitHub is where I share working product and agentic AI pilots based on real problems I have encountered across product development, program delivery, internal tooling, automation, evaluation, data workflows, customer operations, and enterprise governance.

Each pinned repository explains:

* The business problem
* The product and system approach
* Architecture and implementation decisions
* Delivery tradeoffs and constraints
* Evaluation and governance
* What I learned

I started this practice in April 2026 to keep building, deepen my applied AI skills, and make my product and program management thinking more concrete through working systems.
